# Средние сервисы

30 отдельных сервисов. Это не папка `services/` с короткими заготовками.

| Папка | Сценарий |
|---|---|
| `01_checkout_saga` | Отказ оплаты возвращает остаток |
| `02_transactional_outbox` | Повтор события не плодит счёт |
| `03_oauth2_server` | Свой код авторизации и ротация refresh |
| `04_inventory_reservation` | Два заказа не продают один остаток |
| `05_notification_hub` | Выключенный канал не вызывается |
| `06_circuit_breaker` | После трёх ошибок апстрим не дёргается |
| `07_idempotent_payments` | Тот же ключ не списывает дважды |
| `08_subscriptions` | Второй отказ отменяет подписку |
| `09_usage_quotas` | Месячный лимит, не частота запросов |
| `10_promo_codes` | Скидка, срок, лимит и пригласивший |
| `11_two_factor` | TOTP и одноразовый запасной код |
| `12_api_keys` | Scope, ротация, отзыв |
| `13_gdpr_erasure` | Выгрузка, затем стирание личности |
| `14_audit_log` | Журнал только дописывается |
| `15_sessions` | Выход с одного устройства не гасит другое |
| `16_booking` | Пересекающиеся слоты нельзя занять |
| `17_document_workflow` | Автор не согласует свой документ |
| `18_invoice_numbers` | Аннулированный номер не переиспользуется |
| `19_csv_import` | Плохие строки не роняют верные |
| `20_multi_tenant` | Чужой арендатор не видит заметку |
| `21_webhook_dispatcher` | Повтор доставки и подпись тела |
| `22_dlq_replay` | Три ошибки, потом ручной возврат |
| `23_upload_pipeline` | Не-PNG не становится готовым |
| `24_report_jobs` | Скачивание только после готовности |
| `25_schema_registry` | Убрать обязательное поле нельзя |
| `26_autocomplete` | Префикс, синоним и одна опечатка |
| `27_chat_rooms` | Чужой не пишет, пока не вошёл |
| `28_cdc_projector` | Витрина отстаёт, пока её не спроецировали |
| `29_tracing` | Ошибка склада помечает и заказ |
| `30_feature_flags` | Список допуска сильнее нулевого процента |

Проверка всех сразу: `pytest` из этой папки. Проверка одного: `pytest test_main.py` из его каталога. Поднять один сервис: `docker compose up --build` из его папки. CI: `.github/workflows/medium-services.yml`.
