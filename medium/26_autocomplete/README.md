# Autocomplete

## 🎯 1. Описание Бизнес-Задачи
Поиск по каталогу должен находить товар по началу слова, по синониму и по одной опечатке. «кру» находит кружку, «mug» тоже, «чашкв» находит чашку. Это подсказки, а не полнотекстовый индекс базы.

## ⚙️ 2. Обоснование Архитектурного Выбора
Синонимы задаются у товара, а не угадываются. Опечатка допускается только для слов от четырёх букв и только на одну правку, иначе короткий мусор начинает совпадать со всем. Расстояние считается вручную, без внешней поисковой системы.

## 🗄️ 3. СУБД и Хранилища Данных
Каталог в памяти процесса: подсказок мало, и тест не должен поднимать Elasticsearch. В бою те же правила можно повесить на индекс, форма ответа не меняется.

## 🔄 4. Интеграции и Сложный Стек
- Docker-порт `8126`. Проверка: `pytest test_main.py`.
- Контейнер: `docker compose up --build` из этой папки, порт `8126`.
- CI: `.github/workflows/medium-services.yml` на push запускает `pytest test_main.py` и `docker compose config`.
