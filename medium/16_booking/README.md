# Booking

## 🎯 1. Описание Бизнес-Задачи
Слот переговорки нельзя отдать двум людям на пересекающееся время. Соседние слоты, которые только касаются границей, не конфликтуют. Отмена освобождает интервал, после неё то же время можно занять снова.

## ⚙️ 2. Обоснование Архитектурного Выбора
Пересечение считается как `start < other.end and end > other.start`, а не сравнением «свободно/занято» на весь день. Проверка и вставка идут в одной транзакции. Отменённые записи не участвуют в проверке.

## 🗄️ 3. СУБД и Хранилища Данных
Ресурсы и брони в SQLite. Время хранится строкой ISO, сравнение лексикографическое. В бою те же интервалы в PostgreSQL с `tstzrange`.

## 🔄 4. Интеграции и Сложный Стек
- Docker-порт `8116`. Проверка: `pytest test_main.py`.
- Контейнер: `docker compose up --build` из этой папки, порт `8116`.
- CI: `.github/workflows/medium-services.yml` на push запускает `pytest test_main.py` и `docker compose config`.
