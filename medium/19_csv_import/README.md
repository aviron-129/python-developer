# CSV Import

## 🎯 1. Описание Бизнес-Задачи
Файл загрузки товаров редко бывает целиком верным. Верные строки сохраняются, битые попадают в отчёт об ошибках, дубль артикула не затирает уже принятую строку. Импорт не падает целиком из-за одной плохой строки.

## ⚙️ 2. Обоснование Архитектурного Выбора
Парсер свой, без библиотеки таблиц: формат известен, колонки три. Ошибки собираются по номеру строки, а не одним сообщением «файл плохой». Вставка принятых строк идёт в одной транзакции файла.

## 🗄️ 3. СУБД и Хранилища Данных
Товары в SQLite, артикул — первичный ключ. В бою та же таблица на PostgreSQL, файл может приходить из S3.

## 🔄 4. Интеграции и Сложный Стек
- Формат строки: `sku,name,qty`.
- Docker-порт `8119`. Проверка: `pytest test_main.py`.
- Контейнер: `docker compose up --build` из этой папки, порт `8119`.
- CI: `.github/workflows/medium-services.yml` на push запускает `pytest test_main.py` и `docker compose config`.
