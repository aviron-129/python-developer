# Sessions

## 🎯 1. Описание Бизнес-Задачи
У человека несколько устройств. Выход с телефона не должен выкидывать ноутбук. Выход отовсюду гасит все токены сразу. Отозванный токен больше не открывает `/me`.

## ⚙️ 2. Обоснование Архитектурного Выбора
В базе хранится хэш токена, не сам токен. Список сессий отдаёт устройство и флаг отзыва, но не секрет. Это про устройства, а не про JWT из коротких сервисов: здесь сессию можно найти и отозвать поштучно.

## 🗄️ 3. СУБД и Хранилища Данных
Сессии в SQLite. Поиск при запросе идёт по хэшу. В бою та же таблица на PostgreSQL.

## 🔄 4. Интеграции и Сложный Стек
- Заголовок `Authorization: Bearer`.
- Docker-порт `8115`. Проверка: `pytest test_main.py`.
- Контейнер: `docker compose up --build` из этой папки, порт `8115`.
- CI: `.github/workflows/medium-services.yml` на push запускает `pytest test_main.py` и `docker compose config`.
