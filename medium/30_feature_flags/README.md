# Feature Flags

## 🎯 1. Описание Бизнес-Задачи
Функцию можно включить проценту пользователей и списку арендаторов. Ноль процентов выключает всех, кроме списка допуска. Сто процентов включает остальных. Один и тот же пользователь всегда попадает в тот же бакет.

## ⚙️ 2. Обоснование Архитектурного Выбора
Бакет считается из хэша имени флага и пользователя, а не из случайного числа на каждый запрос. Иначе кнопка мигала бы. Список допуска проверяется раньше процента: внутренний арендатор видит функцию даже при нуле.

## 🗄️ 3. СУБД и Хранилища Данных
Флаги в SQLite. Оценка не пишет строку на пользователя: липкость выводится из хэша. В бою флаг можно положить в Redis, формула бакета та же.

## 🔄 4. Интеграции и Сложный Стек
- Docker-порт `8130`. Проверка: `pytest test_main.py`.
- Контейнер: `docker compose up --build` из этой папки, порт `8130`.
- CI: `.github/workflows/medium-services.yml` на push запускает `pytest test_main.py` и `docker compose config`.
