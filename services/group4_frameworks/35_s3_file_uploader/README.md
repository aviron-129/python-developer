# #35 S3 / MinIO Async File Upload Manager

## 🎯 1. Описание Бизнес-Задачи (MVP)
Загрузка файлов в S3/MinIO с компрессией.

## ⚙️ 2. Обоснование архитектурного выбора
Это набросок сценария, не рабочий сервис. В коде нет фреймворка и базы.

## 🗄️ 3. СУБД и хранилища
Своей базы в этой папке нет.

## 🔄 4. Интеграции
Нет очереди, Docker Compose и CI. Рабочие сервисы с compose и тестами лежат в `medium/`.
